# Contributing

This is a personal record, so the main audience is me. If you want your own, fork it and change `entries.yaml`.

## Workflow

- One branch per change, named for what it does (`index-renderer`, `fill-seed-entries`).
- Open a pull request rather than pushing to `main`. The PR description says what changed and where a reviewer would push back, not just which files moved.
- Keep commits scoped and the message leading. I review, then merge.

## Adding an entry

Add a block to `entries.yaml` following the schema in `docs/one-pager.md`. `tldr` is the lesson you took. `why` is the context you were in when it resonated. They stay separate.
